插件

Plugins
插件放在 data/plugins/ 下面， 一个插件一个文件夹，里面放 metadata.json 和 main.py。
启用 / 停用立刻生效（命令和消息钩子马上响应或不响应）； 改完插件代码点右上角重新加载即可，不用重启程序。
注意：插件是用 Python 写的，装插件等于让它的代码在你电脑上运行，只装你信得过的。
