# 配置项

> 本文是 [Nekolyra README](../README.md) 的详细章节，拆出来是为了让首页短一点。

## 配置项

配置在程序目录下的 `config.json`，第一次启动自动生成，**共 113 个默认键**。
大部分能在管理页里改（改完热重载）。

**只能改文件、管理页改不了的六个键**：

| 键 | 默认 | 为什么 |
|---|---|---|
| `superusers` | `[]` | 超管 QQ 列表，接口刻意不给改 |
| `port` | `8080` | 改端口要重启，热重载没意义 |
| `ai_enabled` | `true` | 不在白名单里 |
| `notify_admin_on_request` | `true` | 不在白名单里 |
| `ai_fallback_models` | `""` | 不在白名单里 |
| `ai_rpm_limit` | `45` | 不在白名单里 |

<details>
<summary><b>插件 / 插件市场</b></summary>

| 键 | 默认 | 说明 |
|---|---|---|
| `plugin_timeout` | `15.0` | 插件 handler 的默认超时秒数。超时按失败算，**消息继续往下走**（可能被 AI 接走）；单个 handler 可以用 `timeout=` 自己声明更长的 |

> 环境变量 `NEKOE_PLUGIN_MARKET` 改的是进程环境，**必须重启**才生效；
> 插件市场页顶部显示的「索引地址」是启动时算好的，重启才会跟着变。

</details>

<details>
<summary><b>语音 / 识图 / 表情 / 外观</b></summary>

**语音（TTS）** —— 怎么装 IndexTTS 见[语音详细说明](部署指南.md#语音详细说明)。

| 键 | 默认 | 说明 |
|---|---|---|
| `voice_enabled` | `false` | 语音总开关，关着只发文字 |
| `voice_api_url` | `http://127.0.0.1:7861/v1/audio/speech` | IndexTTS 的 OpenAI 兼容地址（**键名是 `voice_api_url`，不是 `voice_host`**） |
| `voice_api_key` | `""` | 服务端要鉴权才填，会以 `Authorization: Bearer` 发出去 |
| `voice_name` | `""` | 默认音色名；**留空就直接跳过、不发语音**（音色列表从服务的 `/v1/audio/voices` 拉） |
| `voice_speed` | `1.0` | 语速，0.5–2.0 |
| `voice_timeout` | `90` | 单次合成的超时秒数，5–600 |
| `voice_random_chance` | `0.0` | 没命中触发词时**也**发语音的概率 |
| `voice_trigger_keywords` | `["语音","说话","念出来","读出来","讲给我听","voice"]` | 命中这些词就发语音 |
| `voice_max_chars` | `200` | 回复超过这么多字就转纯文字，10–2000 |
| `voice_emotion_mode` | `"vector"` | `vector`（8 维情感向量，断句更自然）/ `speaker`；填别的值按 `speaker` 处理并记一条警告 |
| `voice_emotion_vector` | `[0.1,0,0,0,0,0,0,0.4]` | 8 维情感向量：喜、怒、哀、惧、厌恶、低落、惊喜、平静 |
| `voice_emotion_strength` | `0.65` | 情感强度，0–1 |
| `voice_emotion_voices` | `{"平静":"voice-平静","喜":"voice-喜","怒":"voice-怒","哀":"voice-哀","惧":"voice-惧","惊喜":"voice-惊喜","低落":"voice-哀","厌恶":"voice-怒"}` | 情绪专用音色映射，**优先于情感向量**：映射命中时不传向量参数；映射到的音色被删了会自动退回能用的 |
| `voice_postprocess_preset` | `"deharsh"` | 音频后处理：`off / voice_clarity / clear_narration / deharsh / warm / normalize`，`off` 时整段参数都不发 |
| `voice_postprocess_strength` | `1.0` | 后处理强度，0–1（只在上面的 preset 不是 `off` 时生效） |
