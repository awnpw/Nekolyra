三、常见问题

发了不回复？

  • 确认是在叫它（@ 或写名字）——群里随口说话它不一定接
  • 命令要精确：签到 可以，我要签到了 不行（那种走 AI）
  • 它可能被停用了，看管理页的插件卡片

换老婆没反应？

  • 先看积分够不够（我的积分），换一次要消耗积分
  • 每天换的次数有上限（默认 200）
  • 如果回的是 AI 聊天内容，说明命令没匹配上——把原话和管理页日志发给群主

语音条只播一分钟 / 发不出来？

  • QQ 客户端对语音条本身有播放上限，长歌会被截断，这是 QQ 的限制
  • 发不出来时插件会自动改发音乐卡片或链接

说说没发出来？

  • 她的节奏由模型决定，可能决定「这次不发」
  • 协议端的空间接口偶尔失败，看管理页日志里的「发说说失败」

我自己能改什么？

插件卡片上点「配置」就能改，比如：点歌是否发语音条、语音最长多少秒、老婆每天能换几次、播报时间与城市、表情自动发送的概率等。改完不用重启。

四、给群主（管理员）

  • 管理页：程序启动后打开 http://127.0.0.1:8080/admin/，第一次要带 token（在程序目录的 config.json 里，字段 admin_token）
  • 插件：管理页「插件」页可以启用 / 停用 / 配置 / 重新加载；改完插件代码点「重新加载」即可，不用重启
  • 插件市场：管理页「插件」→「插件市场」里浏览、安装、升级插件，不用手动解压； 装好的在「已安装」页启用。索引地址由环境变量 NEKOE_PLUGIN_MARKET 决定
  • 投稿审核：市场里的插件由市场站长审核通过后才上架；程序本体不含审核功能
  • 更新：管理页「检查更新」→ 下载 → 覆盖更新；失败会自动回滚到上一版，日志在 data/updates/update.log
  • 备份：把整个 data/ 目录拷走即可（数据库、插件、表情、配置都在这）
  • 日志：startup.log；每条消息有追踪 id，排查时按 id 搜最快
